RepoReady
GitHub API + Google Gemma 4

Open source beyond Hacktoberfest starts with a welcoming repo.

Newcomers bounce off repos with no setup guide, no license and no starter issues. RepoReady checks 12 contributor-readiness signals from the GitHub API, scores the repo, then Gemma 4 writes a prioritised fix list, three starter issues and a CONTRIBUTING.md tailored to the project.
